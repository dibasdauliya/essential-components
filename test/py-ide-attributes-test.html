PyIDE Component - Save Button & localStorage Control

Example 1: Default behavior (Save button visible, localStorage enabled)

This is the default behavior with both save button and localStorage enabled.
print("Hello from default PyIDE!") print("Save button is visible and localStorage is enabled")

Example 2: No save button, localStorage disabled

Save button is hidden and localStorage is disabled. Developer would handle saving externally.
print("No save button visible!") print("localStorage is disabled") print("Developer handles saving externally")

Example 3: Save button visible, localStorage disabled

Save button is visible but localStorage is disabled. The save event can be handled by the developer.
print("Save button is visible!") print("But localStorage is disabled") print("Developer can listen to 'save' event")

Example 4: No save button, localStorage enabled

Save button is hidden but localStorage auto-save is still working.
print("No save button!") print("But localStorage auto-save works") print("Changes are saved automatically")
