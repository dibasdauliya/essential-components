Simple ChatUI Example

Key Features:

1. Get User Messages

// Get the last user message const lastMessage = chatUI.getLastUserMessage(); console.log(lastMessage.text); // Get all user messages const userMessages = chatUI.getUserMessages(); // Get all messages (user + bot) const allMessages = chatUI.getAllMessages();

2. Manual Bot Responses

// Send a bot response manually chatUI.sendBotResponse("Hello! How can I help you?");

3. Listen for User Messages

// Method 1: Using callback chatUI.setUserMessageCallback((message, chatInstance) => { console.log('User said:', message.text); // Analyze message and respond chatInstance.sendBotResponse("Got it!"); }); // Method 2: Using event listener chatUI.addEventListener('user-message', (event) => { const message = event.detail.message; console.log('User message:', message.text); });
