# Chat UI

The `<chat-ui>` component is an interactive custom element that provides a complete chat interface with message display, input field, and programmable response handling. It features a modern design with customizable gradients, timestamps, smooth scrolling, and full programmatic control over message flow.

## Installation

To use the `<chat-ui>` component, first ensure you have installed the `essential-components` package in your project.

```bash
npm install essential-components
```

## Import

Import the component in your JavaScript or TypeScript file:

```javascript
import "essential-components/src/chat-ui";
```

## Usage

After importing, you can use the `<chat-ui>` component in your HTML or JSX. The component works out of the box with manual response control for maximum flexibility.

### Basic Example

```html
<chat-ui></chat-ui>
```

### With Custom Title and Placeholder

```html
<chat-ui title="Support Chat" placeholder="How can we help you today?">
</chat-ui>
```

### With Custom Colors and Gradients

## Features

- **💬 Real-time Messaging**: Interactive chat interface with instant message display
- **🎯 Manual Control**: Full programmatic control over bot responses (no auto-responses)
- **📩 Message API**: Get user messages and send bot responses programmatically
- **🎨 Customizable Colors**: Fully customizable gradients and color schemes
- **📞 Event Handling**: Callbacks and events for user message processing
- **⏰ Timestamps**: Each message includes a timestamp showing when it was sent
- **📱 Modern Design**: Beautiful customizable gradient themes with rounded corners and shadows
- **🔄 Smooth Scrolling**: Auto-scrolls to latest messages
- **⌨️ Keyboard Support**: Send messages with Enter key
- **📱 Responsive Layout**: Adapts to different container sizes
- **🎨 Message Types**: Distinct styling for user and bot messages
- **🧹 Message Management**: Clear messages and retrieve message history

## Programmatic API

### Getting Messages

```javascript
const chatUI = document.querySelector("chat-ui");

// Get the last user message
const lastMessage = chatUI.getLastUserMessage();
console.log(lastMessage?.text);

// Get all user messages
const userMessages = chatUI.getUserMessages();

// Get all messages (user + bot)
const allMessages = chatUI.getAllMessages();
```

### Sending Messages

```javascript
// Send a bot response manually
chatUI.sendBotResponse("Hello! How can I help you?");

// Add a user message programmatically (optional)
chatUI.addMessage("User message", "user");
```

### Message Management

```javascript
// Clear all messages
chatUI.clearMessages();
```

### Event Handling

#### Method 1: Using Callbacks

```javascript
chatUI.setUserMessageCallback((message, chatInstance) => {
  console.log("User said:", message.text);

  // Analyze the message and respond
  const response = analyzeMessage(message.text);
  chatInstance.sendBotResponse(response);
});
```

#### Method 2: Using Event Listeners

```javascript
chatUI.addEventListener("user-message", (event) => {
  const message = event.detail.message;
  const chatInstance = event.detail.chatUI;

  console.log("User message:", message.text);

  // Process and respond
  chatInstance.sendBotResponse("Thanks for your message!");
});
```

### Message Object Structure

Each message object contains:

```javascript
{
  id: 1640995200000,           // Timestamp-based unique ID
  text: "Hello world",         // Message content
  type: "user",                // "user" or "bot"
  timestamp: Date             // JavaScript Date object
}
```

## Message Types

The component supports two types of messages:

### User Messages

- Aligned to the right
- Uses `primary-gradient` background
- White text
- Timestamp aligned right

### Bot Messages

- Aligned to the left
- Uses `bot-message-bg` background
- Uses `bot-message-color` text
- Timestamp aligned left

## Advanced Usage Examples

### Simple Bot with Keyword Responses

```javascript
const chatUI = document.querySelector("chat-ui");

chatUI.setUserMessageCallback((message, chatInstance) => {
  const text = message.text.toLowerCase();
  let response = "";

  if (text.includes("hello")) {
    response = "Hello! Nice to meet you! 👋";
  } else if (text.includes("help")) {
    response = "I'm here to help! What do you need?";
  } else if (text.includes("time")) {
    response = `The current time is ${new Date().toLocaleTimeString()}.`;
  } else {
    response = "That's interesting! Tell me more.";
  }

  setTimeout(() => {
    chatInstance.sendBotResponse(response);
  }, 500);
});
```

### Sentiment Analysis Bot

```javascript
chatUI.setUserMessageCallback((message, chatInstance) => {
  const sentiment = analyzeSentiment(message.text);
  const response = `I detect a ${sentiment} sentiment in your message. How can I help?`;

  setTimeout(() => {
    chatInstance.sendBotResponse(response);
  }, 600);
});

function analyzeSentiment(text) {
  const positiveWords = ["good", "great", "awesome", "love", "happy"];
  const negativeWords = ["bad", "terrible", "hate", "sad", "angry"];

  const lowerText = text.toLowerCase();
  const hasPositive = positiveWords.some((word) => lowerText.includes(word));
  const hasNegative = negativeWords.some((word) => lowerText.includes(word));

  if (hasPositive && !hasNegative) return "positive";
  if (hasNegative && !hasPositive) return "negative";
  return "neutral";
}
```

### Integration with External APIs

```javascript
chatUI.setUserMessageCallback(async (message, chatInstance) => {
  // Show typing indicator (you can send a temporary message)
  const typingMessage = chatInstance.sendBotResponse("🤔 Thinking...");

  try {
    // Call your API
    const response = await fetch("/api/chat", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ message: message.text }),
    });

    const data = await response.json();

    // Replace typing indicator with real response
    chatInstance.clearMessages(); // Remove "Thinking..." message
    chatInstance.sendBotResponse(data.reply);
  } catch (error) {
    chatInstance.sendBotResponse(
      "Sorry, I'm having trouble connecting right now."
    );
  }
});
```

## Behavior

### Message Flow

1. **User Input**: Type message and press Enter or click Send
2. **Message Display**: User message appears on the right with timestamp
3. **Event Trigger**: `user-message` event fires and callback is called
4. **Manual Response**: Your code decides how to respond
5. **Auto Scroll**: Chat automatically scrolls to show latest messages

### Input Handling

- **Enter Key**: Sends the message when pressed
- **Send Button**: Click to send message
- **Empty Messages**: Prevents sending empty or whitespace-only messages
- **Input Clearing**: Input field clears after sending

### No Auto-Responses

Unlike basic chat components, this component does **not** automatically generate responses. This gives you complete control over the conversation flow and allows for:

- Custom AI integration
- API-based responses
- Complex conversation logic
- Manual moderation
- Real-time human responses

## Migration from Auto-Response Version

If you're upgrading from a version with automatic responses:

```javascript
// OLD: Auto-responses were built-in
// No additional code needed

// NEW: Manual control required
chatUI.setUserMessageCallback((message, chatInstance) => {
  // Your response logic here
  const response = getBotResponse(message.text);
  chatInstance.sendBotResponse(response);
});

function getBotResponse(userMessage) {
  const responses = [
    "That's interesting! Tell me more.",
    "I understand what you're saying.",
    "Thanks for sharing that with me.",
    "How do you feel about that?",
    "That's a great point!",
    "I'm here to help. What else would you like to discuss?",
  ];
  return responses[Math.floor(Math.random() * responses.length)];
}
```
